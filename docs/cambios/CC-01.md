# CC-01 — APK de Android para el artesano; web para el comprador

- Fecha: 2026-10-10
- Solicitado por: equipo
- Afecta: CU-00, CU-01, CU-02, CU-03; PRP 000–003; `docs/decisiones/0001-stack.md`; `docs/plan.md`

## Cambio
En el plan aprobado, comprador y artesano usaban una misma PWA. Ahora la experiencia se separa:
- **Comprador y administrador:** página web.
- **Artesano:** APK de Android, empaquetada con Capacitor a partir del mismo código React.

## Motivo
Se prioriza Android para el artesano. Una APK abre sin conexión sin depender del navegador y da acceso al reconocimiento de voz nativo. Además separa las experiencias de vendedor y comprador, como recomendaron los mentores.

## Impacto
- **Alcance:**
  - Entran la configuración de Capacitor/Android, el deep link para el login con Google, el plugin de voz nativo y la compilación e instalación de la APK.
  - Sale el requisito de que la PWA sea instalable para el artesano. La web del comprador sigue siendo adaptable a celular y laptop.
- **Tiempo:** estimado en +2–3 h-persona sobre el PRP 000 y el PRP 001. **No está medido.**
- **Archivos / contratos:** `docs/decisiones/0001-stack.md`, `docs/plan.md`. Todavía no hay contratos definidos.
- **Riesgos:**
  - Login con Google por deep link con Capacitor: sin verificar.
  - Necesidad de Android Studio o JDK en al menos una máquina.
  - Instalación desde "orígenes desconocidos" en los celulares de la demo.
  - El reconocimiento de voz nativo no documenta el modo sin conexión.

## Decisión
- Resultado: aprobado
- Decide: equipo · Fecha: 2026-10-10
- Acciones: PRP 000 pasa a "Base web + APK Capacitor"; el PRP 001 incluía el deep link de login (reemplazado por CC-03: correo y contraseña en la APK); el PRP 002 usa el plugin de voz.
